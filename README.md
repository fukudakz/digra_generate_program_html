## 日本デジタルゲーム学会 年次大会プログラム生成スクリプト

このディレクトリは、学会プログラム（HTML）を自動生成するためのスクリプト群です。  
メインスクリプトは `generate_program_html.py` です。

---

### 1. ディレクトリ構成

- `generate_program_html.py`  
  セッション情報・発表情報からプログラムHTMLを生成するメインスクリプト。

- `source/`
  - `session.csv`  
    セッション一覧（日時・会場・セッション名など）。
  - `talk.csv`  
    各セッションに属する発表一覧。
  - `conference_name.txt`  
    HTML の `<title>` とページ先頭の `h1` に表示する大会名。

- `output/`
  - `program.html`  
    生成されたプログラムページ（このファイルが成果物）。

---

### 2. 前提環境

- Python 3.x（標準ライブラリのみ使用）
- 文字コードは UTF-8 を想定

---

### 3. 入力ファイル仕様

#### 3-1. `source/session.csv`

ヘッダ行＋データ行で、カンマ区切りのCSVです。

必須カラム:

- `セッションID`  
- `セッション名`  
- `日付`  … 例: `2026-2-21`  
- `時間`  … 例: `10:10〜11:30`  
- `座長`  
- `会場`  … 例: `教室2 21-313`

`セッションID` は文字列として扱われ、`talk.csv` の `所属するセッション` と対応づけに使われます。

#### 3-2. `source/talk.csv`

必須カラム:

- `発表ID`  
- `easychair_paper_ID`（空でも可）  
- `所属するセッション` … `session.csv` の `セッションID` に対応  
- `著者`  
- `タイトル`

同じセッションIDに属する発表が、プログラム内でそのセッションの下に並びます。

#### 3-3. `source/conference_name.txt`

1行だけのテキストファイルで、大会名（ページタイトル）を指定します。

例:

```text
日本デジタルゲーム学会 第16回年次大会 プログラム
```

この内容が:

- `<title>...</title>`
- ページ先頭の `<h1>...</h1>`

に反映されます。

### 5. 生成されるHTMLの構造

1. **ページタイトル / 見出し**
   - `conference_name.txt` の内容を `<title>` と `<h1>` に表示。

2. **タイムテーブル（会場×時間）**
   - セクション「タイムテーブル」で、日付ごとに:
     - 行: 時間帯（`時間` カラム、開始時刻でソート）
     - 列: 会場（`会場` カラムのユニーク値）
     - セル: その時間帯・会場で行われるセッション名（複数あれば改行）
     - セッション名は、下部「プログラム詳細」の該当セッションへのページ内リンクになっています。

3. **プログラム詳細**
   - セクション「プログラム詳細」で、日付ごとに:
     - 時間帯ごとの見出し
     - 各セッション:
       - 場所（会場名） … `session-location` クラス
       - セッション名 … `session-title` クラス  
         （タイムテーブルからのリンク先アンカー `id="session-<セッションID>"`）
       - 座長（あれば表示）
       - 発表タイトル＋著者リスト（`talk.csv` から）

4. **CSS**
   - ページ上部の `<style>` 内で、サンプルページに近い雰囲気のレイアウトと配色を定義しています。
   - スマートフォン向けに簡易なレスポンシブ対応も含みます。

---

### 6. カスタマイズのヒント

- **大会名を変える**  
  `source/conference_name.txt` の1行目を書き換えてから、スクリプトを再実行してください。

- **セッションや発表を追加/修正する**  
  `source/session.csv` と `source/talk.csv` を編集してから、再度スクリプトを実行してください。

- **デザインを変更する**  
  `generate_program_html.py` 内の `<style>` ブロックを編集すると、ページの見た目を変更できます。

---

### 7. 注意点

- CSVは **UTF-8** で保存してください。
- `セッションID` と `所属するセッション` は、一致している必要があります。
- `時間` のフォーマットは `HH:MM〜HH:MM` 形式（`〜` または `～`）を想定しています。ここから開始時刻を抽出してソートします。
